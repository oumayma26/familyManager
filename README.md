## 📋 Description

Family Manager est une application desktop développée avec **PySide6** permettant de :

- 📇 **Gérer un registre des martyrs** et leurs familles
- 🌳 **Visualiser l'arbre généalogique** des familles
- 💰 **Calculer et gérer les pensions** selon le SMIG tunisien
- 📅 **Suivre l'historique des paiements** mensuels
- 💾 **Sauvegarder et restaurer** la base de données
- 📊 **Consulter les statistiques** globales
